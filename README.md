# Flashcards Maker

Додаток для створення та вивчення флеш-карток, розроблений студентками 2 курсу спеціальності «Комп'ютерні науки» — **Анастасією Мікулич** (Team Lead та Backend розробник) та **Діаною Пінчук** (Frontend розробник).

## Інструкція для користувача (Локальний запуск)

### Запуск в Інтернеті
Додаток повністю розгорнутий у хмарі та готовий до використання. Вам не потрібно нічого завантажувати чи налаштовувати локально.

Посилання на працюючий проєкт: [Flashcards Maker на Render](https://c-3-final-stage-project-in-collaration.onrender.com)

Просто перейдіть за посиланням, зареєструйтеся (або увійдіть через Google) та починайте навчання.

### Запуск локально
Щоб запустити цей проєкт на своєму комп'ютері з локальною або тестовою базою даних, виконайте наступні кроки:

1. Склонуйте цей репозиторій на свій комп'ютер
2. Перейдіть на гілку dev
3. **Налаштування конфігурації:** Скопіюйте файл `appsettings.json` та створіть на його основі новий файл з назвою `appsettings.Development.json`.
4. **Додавання ключів:** Відкрийте створений `appsettings.Development.json` та впишіть туди свої власні API-ключі та ваш рядок підключення до бази даних (Connection String).
5. **Міграції бази даних:** Запустіть консоль у папці з проєктом та виконайте команду для створення таблиць у вашій базі даних:
   ```bash
   dotnet ef database update
   ```
6. Запустіть свій проєкт 
    ```
    dotnet run
    ```

## Опис користувачів програми
Основна аудиторія Flashcards Maker охоплює кілька категорій користувачів, об’єднаних потребою в систематизації та запам’ятовуванні великих обсягів інформації. 
- Першу групу складають **здобувачі освіти (школярі та студенти)**, для яких програма є інструментом підготовки до іспитів, тестів або вивчення академічних дисциплін. Ця категорія користувачів потребує можливості створювати структуровані колекції карток за предметами та використовувати режим вікторини для швидкої самоперевірки перед контрольними заходами.
- Другою важливою групою є **особи, що вивчають іноземні мови**. Для них ключовим функціоналом є робота з парами «термін — визначення» (слово — переклад) та можливість групувати лексику за тематичними категоріями. 
- Окрему категорію становлять **спеціалісти різних галузей**, які проходять професійну сертифікацію або підвищення кваліфікації. Їм програма допомагає тримати під рукою складну термінологію та технічні дані, використовуючи функції швидкого пошуку та фільтрації для миттєвого доступу до потрібних відомостей. 

Загалом застосунок орієнтований на всіх, хто потребує зручного цифрового сховища для персональної бази знань із можливістю кастомізації інтерфейсу під власні візуальні вподобання.

## Основний функціонал
* **Керування сетами:** Створення, редагування, видалення та перегляд наборів навчальних карток. Налаштування приватності (публічні або приватні сети).
* **Розумна генерація:** Автоматичне створення цілих наборів карток за допомогою штучного інтелекту за текстовим описом теми.
* **Розумні підказки:** Швидке отримання визначень з Вікіпедії або автоматичного перекладу слів прямо під час ручного створення картки.
* **Інтерактивна практика:** Зручний тренажер для заучування карток із CSS-анімацією перегортання, системою оцінювання важкості та фіксацією прогресу.
* **Авторизація:** Безпечний вхід через стандартну форму або в один клік за допомогою Google-акаунта.
* **Профіль користувача:** Збереження особистої статистики, відстеження прогресу вивчення та кастомізація аватарки.

## Використані технології
* **Backend:** .NET 9.0, ASP.NET Core MVC, Entity Framework Core
* **База даних:** PostgreSQL (Хмарний хостинг Neon)
* **Frontend:** HTML5, CSS3, JavaScript
* **Безпека:** JWT Токени, Google OAuth 2.0
* **Сервіси:** Cloudinary (збереження зображень), Google SMTP (відправка системних email)

## Інтеграції API

### Сценарій інтеграції
**Назва**: Автоматизоване створення навчального контексту на основі ШІ та зовнішніх сервісів.

**Проблема користувача**: Користувач хоче швидко створити набір карток для вивчення нової теми, не витрачаючи час на ручне введення кожного слова та пошук визначень.

**Вирішення проблеми (2 варіанти)**:
1. Користувач створює сет за допомогою ШІ, вказавши чіткий опис теми, яку хоче отримати.
2. Користувач створює сет самостійно, але використовує автоматичні підказки для швидкого отримання означення або перекладу термінів.

### Використані зовнішні API
| API | BaseUrl | Endpoint | Отримані дані | Кешування |
|---|---|---|---|---|
| **Gemini** | `https://generativelanguage.googleapis.com/v1beta/` | `interactions` | Згенеровані картки, fallback-підказка | Ні (на бекенді 24 год) |
| **Wikipedia** | `https://{lang}.wikipedia.org/` | `api/rest_v1/page/summary/{term}` | Підказка — означення слова | 24 години |
| **MyMemory** | `https://api.mymemory.translated.net/` | `get?q={term}&langpair={from}\|{to}` | Підказка — переклад слова | 24 години |

### Fallback-стратегії
* Якщо **Wikipedia** або **MyMemory** недоступні -> система автоматично звертається до **Gemini** для генерації підказки (означення чи перекладу).
* Якщо **Gemini** також недоступний для підказки _>_ користувачу відображається нейтральний текст: *"Підказка недоступна, спробуйте пізніше"*.
* Якщо **Gemini** недоступний у момент генерації нового великого сету -> функція блокується, а користувач бачить помилку про тимчасову недоступність опції із закликом спробувати пізніше.
